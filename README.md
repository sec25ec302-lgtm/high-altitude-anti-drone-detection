# High Altitude Anti-Drone Detection System

## Project Overview
AI-based aerial object classification and
environmental monitoring simulation.

## Features
- Radar Simulation
- Drone and Bird Classification
- Altitude Monitoring
- Temperature and Pressure Monitoring
- Simulated Detection Alerts
- Interactive Dashboard

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy

## How to Run
pip install -r requirements.txt

streamlit run app.py

## Note
This project is an educational simulation.
